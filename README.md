# My Recovery Journey — Pacific Northwest Edition

A responsive, cinematic, static recovery and faith website built with HTML, CSS, and JavaScript.

## Publish
In GitHub: Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

## Images
Place these four image files in the `assets/` folder:
- `hero-boardwalk.jpeg`
- `card-road.jpeg`
- `card-trail.jpeg`
- `card-river.jpeg`

Until these assets are uploaded, image backgrounds will be missing. Do not publish reference photographs without confirming usage rights. Use original or licensed replacements if necessary.

## Privacy
Journal and checklist use browser localStorage only. They are not backed up, synced, or password-protected.
